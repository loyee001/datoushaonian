# 大头少年 · 深空任务控制台

对应选定的「深空蓝 · 任务控制台」设计。一个可运行的本地应用，包含教师工作台和统一家长入口。无第三方运行依赖；使用 Node.js 自带 HTTP 服务和 SQLite。

## 启动

需要 Node.js 22.12 或更高版本。双击 `启动课堂.command`，或者在此目录执行：

```bash
npm start
```

教师端：<http://127.0.0.1:4173>。默认演示账号 `teacher`，演示密码 `SpaceClass2026!`。

本地演示模式第一次启动自动建立 6 名虚构学员、一组课程、示例考勤和评价。后续启动保留数据，不会覆盖记录。默认只监听本机；本地地址不能直接发给异地家长。

线上版本已部署至 <https://datou.qdfb.tech>，采用空白数据初始化与独立教师密码。部署与运维步骤见 [deploy/README.md](deploy/README.md)。线上密码仅保存在私有配置中，不使用演示密码。

## 已实现

- 学员档案：编号、家长姓名和手机号、孩子姓名和绰号、年级、性别、项目组、头像；新增、编辑、搜索、按组筛选。
- 项目与课程：项目组、项目名称、队长、项目介绍；一个课程可勾选多个小队，设置共同上课日期、起止时间和学习内容。原有单组课程自动兼容。
- 删除与恢复：学员档案、项目组卡片提供删除按钮；输入对象名称后确认。删除学员同时移除其考勤与评价；删除项目组同时移除组内学员及其记录，仅该组使用的课程一并删除，多队共用的课程和其他小队记录保留。删除内容进入“最近删除”，可整项恢复；恢复时保留共有课程的后续编辑，若原编号被占用或依赖的项目组未恢复，系统会提示处理后再恢复。
- 考勤：已到、迟到、请假、缺席、待点名；请假备注和提醒；今日课程可切换全部小队或单个小队，一键到课仅处理当前范围，并保留已登记请假。
- 评价：日、周、月评价；标签、文字、时间范围；草稿和主动发布；编辑已发布内容后保存为草稿，重新发布才对家长可见。
- 导出：按日期范围、学员、项目组、类型筛选，导出带 UTF-8 BOM 的 CSV，Excel 可直接打开；周/月评价按周期与查询范围相交筛选。
- 统一家长入口：每次课程只有一个共享链接，所有家长进入同一入口；手机号尾号唯一匹配后显示该家长的孩子。跨小队重复尾号要求补充位数，同一家长多个孩子可切换；验证后显示各自小队和项目，仅返回必要资料和已发布反馈。
- SQLite 持久化；教师密码哈希、HttpOnly 会话、登录和家长查询频率限制。
- 手机与电脑响应式布局。

## 一个课程安排多个小队

1. 在“项目与课程”创建各个项目组，并添加学员。
2. 新建或编辑课程，在“参与项目组”中勾选需要一起上课的多个小队。
3. 进入“今日课程”，在“当前小队”切换全部小队或单个小队，也可点击“管理本课小队”调整。
4. 本次学习内容全课共用，评价分别填写。“发布全课反馈”会发布该课程所有小队的日评价；周、月评价仍发布当前孩子的对应评价。
5. 导出时可选本课程全部小队、某队或某个孩子，覆盖选定时间段。

## 数据及配置

数据保存在 `data/classroom.sqlite`，已从源码包和版本控制中排除。请不要删除该目录。备份时先正常停止服务，再复制整个 `data` 目录；运行中有 WAL 文件时不能只复制单个 SQLite 主文件。

可用环境变量：`PORT`（默认 4173）、`HOST`（默认 127.0.0.1）、`DATA_DIR`（数据目录）、`TEACHER_PASSWORD`（本地至少 10 位，生产至少 16 位）、`SEED_DEMO`（是否初始化演示数据）。教师账号固定为 `teacher`。

生产环境必须设置 `NODE_ENV=production`、独立 `TEACHER_PASSWORD` 和准确的 HTTPS `PUBLIC_ORIGIN`；默认不生成演示数据。使用本机反向代理时可设置 `TRUST_PROXY=loopback`，代理需覆盖 `X-Real-IP`。生产环境会验证请求 Host 和写入请求 Origin，并为登录会话启用 Secure Cookie。

为了保留历史记录，有考勤或评价的学员不能直接更换项目组；已有日评价的课程不能直接改日期，可新建课程。课程可继续加入小队；已有考勤或评价的小队不能从该课程取消，避免历史记录错配。当前版本是单机构、单教师账号；未实现短信发送、多老师权限分配、学员批量导入或自动定时备份。
